# Chat Plus

A private communication application for secure chats, voice messages, and calls.

## Current Features

- 💬 Text messages
- 🎤 Voice messages
- 📞 Voice calls
- 📡 Messages that sync when internet returns
- 🔐 Private accounts
- 👨‍👩‍👧‍👦 Private communication
